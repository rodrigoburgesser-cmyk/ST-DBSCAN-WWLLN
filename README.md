ST-DBSCAN analysis of WWLLN lightning data
Overview

This repository contains the Python code used to identify spatiotemporal clusters in lightning location data from the World Wide Lightning Location Network (WWLLN) using the Spatiotemporal DBSCAN (ST-DBSCAN) clustering approach.

The code was developed for the analysis presented in:

Diurnal Variation of Global Lightning and Thunderstorm Activity and Its Relation to the Carnegie Curve

Rodrigo Bürgesser

Journal of Geophysical Research - Atmospheres

Data availability

The analysis uses global lightning location data from the World Wide Lightning Location Network (WWLLN) covering the period 2014–2025.

The original WWLLN data are not included in this repository because access to the data is subject to WWLLN data-access and distribution policies.

WWLLN data are available to network members and can also be obtained by non-members through the WWLLN data access/purchase process.

Researchers interested in obtaining the data should contact WWLLN through:

https://wwlln.net/

To reproduce the analysis, the corresponding WWLLN lightning location files for the required period should be placed in the data/ directory.

The output/ directory contains the CSV files generated by the analysis.

Input data

The code expects WWLLN lightning location files with the .loc extension.

The input files should follow the WWLLN file naming convention used in the analysis, for example:

A20140101.loc
A20140102.loc
A20140103.loc


The code identifies the date from the first eight digits following the initial A.

Each input record is expected to contain, at minimum:

Date

Time

Latitude

Longitude

The original WWLLN file format and data should be obtained directly from WWLLN.

ST-DBSCAN analysis

The code implements a spatiotemporal clustering procedure based on ST-DBSCAN.

The spatial and temporal neighborhood parameters and the minimum number of samples were evaluated over a range of values as part of a parameter-sensitivity analysis.

The final parameter configuration used for the analysis presented in the article was:

Spatial threshold: 10 km

Temporal threshold: 5 min

Minimum number of samples: 2

These values correspond to the parameter configuration selected after evaluating alternative combinations.

Software requirements

The code requires Python 3 and the following Python packages:

NumPy

scikit-learn

The required packages can be installed using:

pip install -r requirements.txt

Running the code

Obtain the required WWLLN data directly from WWLLN.

Place the .loc files in the data/ directory.

Install the required Python packages.

Run:

python st_dbscan_wwlln.py


The resulting cluster summaries are saved as CSV files in the output/ directory.

Output

For each input file, the code generates a CSV file containing the identified clusters.

The output includes:

cluster_id: cluster identification number

start_time: beginning time of the cluster

duration_sec: cluster duration in seconds

num_events: number of lightning events in the cluster

centroid_lat: mean latitude of the cluster

centroid_lon: mean longitude of the cluster

area_km2: estimated cluster area

Reproducibility

The code is provided to facilitate reproducibility of the analysis described in the associated scientific publication.

Because the original WWLLN observations are subject to data-access restrictions, the raw lightning observations cannot be redistributed through this repository. Researchers wishing to reproduce the analysis should obtain the corresponding WWLLN data directly from WWLLN.
